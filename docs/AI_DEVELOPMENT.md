# AI 輔助開發：使用方式與心得

本專案全程使用 **Claude Code** 協作開發，Git 紀錄中標有 `Co-Authored-By: Claude` 的 commit 都是與 AI 一起完成。

## 使用方式

| 由我負責 | 由 AI 協助 |
| --- | --- |
| 決定專案主題與使用情境（中小企業差旅報帳規定問答） | 撰寫 Python、前端與 Terraform 程式 |
| 規劃系統要有哪些部分、資料怎麼流動 | 介紹 GCP 上可用的服務，說明各自的用途 |
| 在 AI 列出的方案中做選擇 | 比較各方案的優缺點、成本與限制 |
| 驗收結果，決定什麼可以交付 | 查證官方文件、撰寫測試與文件、做獨立審查 |

**規則**：AI 不能自行 commit、刪除檔案或部署；雲端服務的版本與區域須查證官方文件；未驗證的部分必須標明。

## 心得

過去我和 AI 合作開發的經驗不少，但多是前端放 Cloudflare、後端用 Google Apps Script 或 GitHub 執行，需要資料庫時再使用免費託管平台的小專案。這次想藉實作機會，用 GCP 這種正式的雲端平台完整規劃一次架構。

我大致知道系統該怎麼規劃，但不認識 GCP 上對應的工具，例如 IAP、Eventarc、Workflows。透過 AI 分析各工具的用途、串接方式與優缺點，再由我做決定，大幅加速了學習過程，也讓我能把心力放在「系統該滿足什麼需求」上。
